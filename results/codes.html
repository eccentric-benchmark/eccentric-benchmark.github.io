How to read this page. The sizes are those of the syndrome circuit of a memory experiment at the code's default schedule: data qubits, and the ancilla qubits that measure the checks. "Logical qubits tracked" counts the logical qubits whose errors the memory experiment detects (for most codes all of them; for the honeycomb code one of its two). A check's weight is the number of data qubits it involves. Floquet codes and the Bacon-Shor code measure pairs of data qubits directly, so their circuits have no ancillas. The drawing places the qubits at the coordinates the circuit gives them, or, where it gives none, by a force-directed layout of the entangled pairs, and links every pair of qubits that a two-qubit gate or measurement acts on. A logical error rate is the fraction of shots in which any tracked logical qubit failed over all rounds; per round it is ε = (1 − (1 − 2P)1/rounds)/2. The results come from the Results Explorer, which lists every configuration.
